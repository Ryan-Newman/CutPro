# CutPro — Progress Tracker

A Premiere-style non-linear video editor, built as a **native Windows desktop app** (WPF, .NET 9).

**Build & run** (from the `CutPro` folder):
```
dotnet run -c Release
```
**Export requirement:** `ffmpeg.exe` (`winget install Gyan.FFmpeg`, or drop it next to `CutPro.exe`; the app also lets you browse to it once and remembers it).

## Architecture
| File | Role |
|---|---|
| `Models.cs` | `MediaItem`, `Clip`, `ProjectFile`, timecode helper |
| `Editor.cs` | Project state, edit operations (add/split/delete/ripple), undo/redo, shared fit/geometry math |
| `Preview.cs` | Program monitor: ffmpeg-decoded frames (FrameStream) + titles/images, synced to the audio clock |
| `AudioOut.cs` / `AudioCache.cs` | Conformed PCM audio cache, in-app mixer, waveOut output = master clock |
| `FrameStream.cs` | ffmpeg rawvideo decode pipe with frame buffer |
| `TimelineView.cs` | Custom-drawn timeline; Premiere-style Selection/Razor tools, linked clips, marquee, gaps, context menu |
| `MediaProbe.cs` | Import via ffprobe (any ffmpeg format: MKV, HEVC, VP9, ProRes, FLAC, Opus…; phone rotation) + ffmpeg thumbnails |
| `Exporter.cs` | Generates an ffmpeg filter graph from the timeline → H.264/AAC MP4 with progress + cancel |
| `MainWindow.xaml(.cs)` | Bin, monitor, transport, effect controls, toolbar, save/open, export flow |

Preview and export share the same geometry (`Editor.Fit`), so what you see is what you render.

## Known limitations
- Very heavy footage (4K 10-bit HEVC) decodes in software; a few frames can lag up to ~0.2 s right after edits during playback; hardware decoding is on the backlog.
- Fixed 1280×720 @ 30 fps sequence; volume max 100%.
